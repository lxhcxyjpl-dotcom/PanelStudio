# v0.3 开发中：通用 AI 连接与内页整理

2026-11-13 根据用户把密钥填入「API 前缀」的反馈，重新整理连接设置和编辑器层次。原有新手引导、对话精修、SVG 导出和排版目标继续保留。

## 连接流程

设置分为「通用」和「AI 连接」。AI 对话中的「连接 AI」直接打开连接表单。

服务商快捷项包括 DeepSeek、OpenAI、OpenRouter、Ollama 和自定义兼容服务。服务地址与模型始终可以修改；当前对接协议仍是 **OpenAI Chat Completions 兼容接口**。原生 Anthropic Messages、Gemini 等协议尚未实现独立适配器；当前也只有一个生效的连接，不是多连接账户管理器。

普通流程为：选择服务商 → 填写 API 服务地址、模型、API 密钥 → 保存并测试。结构化输出方式和本地地址许可收在高级设置中。

- 地址栏识别 `sk-…` 或 `Bearer …` 这类误填，并指向下方的密钥栏。无效网址、网址中的凭据/查询参数、不兼容的 Messages/Responses 路径会在提交前显示提示。
- 密钥为密码输入框，不回显已保存内容。保持同一接口时，留空继续使用已有密钥。更换接口需要填写新密钥。
- 保存和测试可以单独执行。「测试」有未保存内容时会先保存，再发送示例文字；不会上传用户图稿。
- 「连接可用」只表示当前配置版本的文字连接测试成功，不表示已验证视觉理解质量或所有排版指令。
- 连接测试使用独立的简短 JSON schema。已知的 DeepSeek 官方模型在该短测试中显式关闭思考，避免默认思考耗尽 64 token 回复预算；正式排版请求继续使用模型默认模式。依据：[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。这属于按协议做的兼容处理，真实厂商调用仍待用户配置密钥后验证。
- DeepSeek 官方预设使用 `https://api.deepseek.com` 和 `deepseek-flash`，开启图片输入；`deepseek-v4-pro` 会关闭图片输入。其他模型名保留自定义能力选择，未知别名不自动宣称支持图片。
- 本机 Ollama 的默认地址为 `http://localhost:11434/v1`。该地址无鉴权时可不填密钥，兼容客户端使用固定的 `ollama` 占位值；远程地址仍要求 HTTPS。

以上预设依据本次核对的官方文档，模型能力可能随厂商更新：
[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/) · [OpenAI Chat API](https://developers.openai.com/api/reference/resources/chat) · [OpenRouter](https://openrouter.ai/docs/api_reference/overview) · [Ollama](https://docs.ollama.com/api/openai-compatibility)。

## 保存接口

新增 `PUT /api/v1/settings/ai-connection`，请求体为 `{ config, secret? }`，使用现有幂等键。配置和加密密钥在同一数据库事务中保存，返回值不含密钥。切换接口而未提供新密钥时，清除旧密钥；相同规范化 Chat Completions 地址可以继续使用已有密钥。

原有 `/settings/ai-provider` 和 `/secret` 接口保留兼容。旧配置接口也不会把密钥带到不同的服务地址。配置版本更新继续使旧 AI 请求失效。OpenAPI 文档已同步。

主要代码：`SettingsDialog.tsx`、`DialogShell.tsx`、`model/provider-form.ts`、`apps/server/src/ai-jobs.ts`。

## 编辑区

桌面画布与两侧工具区改成有明确边界的面板。素材列表合并重复的格式/使用状态，缩略图上标示已使用；完整信息仍可在素材详情中查看。

右侧栏默认宽度调整到 352 px，可在 320–420 px 范围内调整。原先过窄的已存宽度会回到新默认值。画布详细参数按需展开，编号设置合并为两列。仍使用 13、15、24、56 px 四档 UI 字号。
