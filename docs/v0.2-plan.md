# PanelStudio v0.2 implementation plan

Reference and local baseline: `47a7011551034a8f3c7eb8aa61009191b2e38402`. A detached checkout preserves v0.1 for comparison. Development uses `develop/v0.2`.

| Stage | Implementation and verification |
| --- | --- |
| Baseline | Run the pinned package manager on Windows, record native installation and CRLF/Bash differences in the test record. |
| Protocol and persistence | Normalize root, candidate and clarification context at submission. Migrate SQLite transactionally after producing a consistent backup. Publish a filtered, paged history DTO. |
| Background work | Separate ordered mutations from document snapshots and jobs. Compile and rasterize previews in bounded worker threads, publish terminal state and artifact atomically. |
| Fonts and validation | Share bundled glyph metrics across browser, solver and server. Preserve schema 1, validate legacy label changes per edge, strictly validate layout and replay before accepting. |
| Local arrangement | Construct ordered rows using selected units, real label extents and a single size parameter. Test the 48 × 24 and 48 × 48 mm counterexample. |
| Workspace | Support cumulative AI drafts, root comparisons, selection scope, direct manipulation and accessible sorting in Chinese and English. |
| Acceptance | Drive the running app, export new mixed-material SVGs and open them in the installed Illustrator. Record numeric measurements, edits, native saves and reopen results. |

User-confirmed desktop acceptance target: **Adobe Illustrator**. Protocol fixtures exercise the model adapter. No external inference service is configured for this test.


The implementation and package checks for all seven stages are recorded in the [test record](test-record.md). The compatibility check discovered the legacy importer's unconditional asset-ID remapping. Assets now use a project-scoped key, keeping the complete schema-1 document and its hash on duplicate import. Native Illustrator checks exposed a separate Chinese weight-substitution behavior. The font bundle includes a script that targets only editor-generated labels. Its native measurements are recorded separately from direct-open results in [Illustrator compatibility](illustrator-compatibility.md).
