# PanelStudio v0.3 科研组图排版学习算法草案

第一轮本地实验已经完成，包含 112 幅核对过的组图、按论文留出的比较和独立新稿试排。[实验结果与试用入口](../experiments/layout-learning/README.md)

目标是把 2–8 个已有面板排成一幅可编辑的科研组图。给定同一批素材，作者改变要说明的结论，推荐的阅读顺序、面板分组和主次也应随之改变。首个实现采用预训练视觉语言模型理解内容，从发表组图学习布局结构，再用轻量模型给现有求解器生成的合法候选排序。以下是待验证的设计。

~~~mermaid
flowchart LR
    F["发表组图与图注"] --> D["校正面板框、关系与切分树"]
    D --> T["结构库与条件统计"]
    D --> R["候选排序器"]
    U["用户子图、图注与写作目标"] --> V["识别内容、推断主次和配对"]
    V --> S["结构检索、槽位分配与几何求解"]
    T --> S
    S --> H["硬约束校验"]
    H --> R
    R --> P["预览有区别的候选"]
    P --> J["作者的成对选择"]
    J -. 后续训练 .-> R
~~~

## 1. 一次排版需要什么输入

| 输入 | 作用 |
| --- | --- |
| 每个面板的独立缩略图、当前裁剪后的宽高比、标题或图注（如有） | 判断图型、识别比较对象、估计在最终版心下需要多少空间 |
| 作者可选的一句话主张 | 指出希望读者首先看到的结果，例如“突出两组的定量差异” |
| 画布尺寸、已指定的主图或对照组、锁定对象、最小尺寸与用户偏好 | 确定必须满足的要求和可协商的取舍 |
| 可选的参考图 | 指定参考结构，未提供时从训练库检索相容的结构 |

视觉模型看到等规格展示框中的独立面板，每个面板保留自身宽高比。学习内容时遮住原稿外部编号，并移除原始页面坐标和相对占位面积。面板内的轴、刻度、比例尺和内部图例仍是内容。这样可以检验模型是否真的从内容和图注推断关系。对新稿要复用的编号顺序由编辑器单独保存。

用户还可以用自己的话表达审美偏好。例如“紧凑一点，但两组图要好比较”可以给较小的组内间距和等高对齐加分。参考图提供可量化的面积比例、分组与留白。二者冲突时以作者明确指定的分组或主图为先，在合法范围内为其余取舍提供不同候选。

## 2. 从图中推断哪些内容需要被一起阅读

视觉模型返回每个面板的图型、可能的作用，以及面板间的关系。关系可以是“同一实验的两组对照”“代表图与其定量”“流程图先于结果”或“时间顺序”。每项推断附面板 ID 和可核对的依据，例如共同的组名、图注中引用两幅面板的短句。已有的预览图输入和视觉复核接口提供模型调用入口。这一版还需增加逐面板输入和结构化关系输出。[现有模型调用](../apps/server/src/ai-jobs.ts)

主次有三个来源。作者明确指定的主图和配对直接进入约束。作者给出的一句话主张可与子图标题、图注匹配，生成可修改的重点建议。仅有图片时，模型可以给出并列重点，也可以只识别出对照关系。系统记录推断依据与不确定项。模型自己报出的置信百分比需要单独校准。第一版用“作者指定”“有图注支持”“仅有视觉线索”标明证据。

例如 A、B 是两组代表性图像，C 是同一指标的定量，D 是流程图。作者写“突出组间差异”时，C 可以占主位，A、B 等高相邻。作者写“先解释实验设计”时，D 可以置顶，A、B 和 C 在后面组成证据组。两次都只调整面板的位置和外框尺寸。复用参考图的外观时，仍由各素材决定自身的坐标轴、比例尺与像素内容。

## 3. 从已发表的图中学习布局规律

训练样本的单位是**一幅完整、可对应图注的组图**。保留论文身份、图号、版本和切图来源。每幅图标注顶层面板的归一化外框、内容类型和可判断的关系。标题、跨面板图例和内嵌小图另有归属。PDF 同时含位图、文本和矢量绘图，单独抽取嵌入图片会漏掉只用路径绘制的统计图。先定位图注，结合正文列界、邻近的矢量路径、文本和位图，在原页上圈出候选整图并渲染。用原生文字或局部 OCR 找 a、b、c 等编号，再用面板间的留白与轴框估计边界。图注跨页、编号不全或多个候选区域相连时，保留原页供人工校正。MedICaT 的子图与子图注标注可用来验证对齐方法，药理学组图仍需用本领域样本复核。[PDFFigures 2.0](https://github.com/allenai/pdffigures2) · [MedICaT](https://aclanthology.org/2020.findings-emnlp.191/)

期刊、图型和研究方向用来分层抽样。入库时按最终印刷尺寸，单独标记图例是否可读、对照是否易比较、阅读顺序是否明确。一幅发表图能提供几何观测。要让它成为审美学习的正例，还需要盲评或作者选择提供偏好标签。

每个校正后的样本保留两种表示。

1. **关系图**记录哪些面板相邻、对齐、等高、跨行、共用图例，以及横纵间距和面积份额。语义上的配对独立标注，避免用“空间相邻”定义“属于一组”，再用同一个标签验证相邻规律。
2. **行列切分树**把可分割的组图表示为水平或垂直分区，每个叶子对应一个面板或刚性编组。例如左侧上下两张与右侧跨行一张，可以用两层切分表示。嵌套、特殊拼贴、独立共享图例等超出现有求解器能力的样本单独统计适用范围。多个树能复原同一几何布局时，按几何和邻接关系判断等价。[已有切分树](../packages/layout/src/guided-tree.ts)

第一轮在训练论文里估计几类条件规律。例如在相同面板数和版心宽高比下，对照图等高相邻的频率，带较多轴标签的图通常获得的宽度，以及“代表图＋定量图”的相对面积与间距分布。每条规律保留样本数、涉及的独立论文数和跨论文波动。评估配对效应时，选面板数、面板图型和版心形状相近的非配对子图作比较。少数论文支持的组合向总体分布收缩。发表位置和面积是视觉强调的观测值。科学主次和作者喜好需要另外的证据。

例如要检验“对照组通常等高相邻”，先按图注独立标出所有配对的 $G$ 值，再用位置和对齐误差计算是否等高相邻的 $Y$ 值。在面板数与版心比例相似的组内，比较 $P(Y=1\mid G=1)$ 与 $P(Y=1\mid G=0)$，按论文加权。候选特征在训练与验证论文上筛选，锁定后才在独立测试论文上报告效果。这是待检验的规律示例。文献中确有正文句子直接引用该图时，可将它作为写作目标的弱代理并记录来源。其余样本保留“目标未知”。

## 4. 生成候选，再学习排序

1. 保留 v0.2 默认候选，同时从训练库按面板数、版心形状、关系图检索相容的结构。用户提供的参考图可以直接成为一个候选结构。自动推荐和指定参考图分开评估。
2. 将用户的面板分配到槽位。先按图型、宽高比和阅读次序缩小范围，再用有限宽度的束搜索评估成对相邻、先后顺序等联合代价。明确的锁定、刚性组和用户指定关系在搜索中提前过滤。
3. 按素材真实宽高比、编号实际占位和毫米间距拟合位置。现有验证器重放命令，检查最小尺寸、重叠、页边距、文档约束与锁定。最终只对通过的候选评分。[布局拟合](../packages/layout/src/guided.ts) · [候选验证](../packages/layout/src/validate.ts)
4. 首个排序模型用带正则的线性得分 $s_\theta(x,L)=\theta^\top\phi(x,L)$。特征包括已学结构出现的频率、对照面板共享边长度与对齐误差、主图面积份额、按最终版心估算的文字可读性，以及参考结构的偏离量。位图缺少可靠字号时记录缺失。用户指定的硬约束优先于任何得分。按拓扑和几何去重，在高分结果中选最多三份确有构图差异的布局。

**用文献做弱监督。** 对训练图 $i$，生成合法候选集合 $C_i$，用归一化面板外框和邻接关系找出能近似复原发表版式的子集 $P_i$。在同一幅图内，优化

$$
\ell_i=-\log\frac{\sum_{L\in P_i}\exp s_\theta(x_i,L)}
                      {\sum_{L\in C_i}\exp s_\theta(x_i,L)}.
$$

这项训练估计对发表结构的相容程度。同一论文中的图共同分摊权重，防止一篇多图论文支配模型。等价布局都可进入 $P_i$。阈值只在验证集上选择。若 $P_i$ 为空则计入“候选未覆盖”，不强行制造标签。若所有候选都等价，该组也不贡献区分信号。

为每个训练样本构造 $C_i$ 时也屏蔽本论文、转载图，以及裁切或改色造成的内容近重复。不同论文用不同素材采用同一构图时，保留这些独立先例。候选预算与推理时相同。另设一项“用户已给参考”的实验，用独立的新素材验证参考结构迁移。

**用真实选择学习偏好。** 给作者同一批素材、同一句写作目标、同一版心的两份候选，随机左右位置，记录 A、B、平局或都不可用。用明确的偏好对拟合一个小的排序修正项，成对选择概率取 $\sigma(s_A-s_B)$。平局和都不可用单独统计，未看过的候选不生成偏好标签。个人偏好由用户确认保存，当前稿件的面板 ID 不跨项目继承。[成对排序方法](https://www.microsoft.com/en-us/research/publication/learning-to-rank-using-gradient-descent/)

## 5. 怎么验证，以及什么时候值得增加模型规模

先按整篇论文和重复图簇划分训练、验证和测试。处理同 DOI 多版本，以及综述转载原图造成的跨论文近重复。检索库、条件统计和模型参数都只由训练部分建立。另留一组不同期刊或不同图型的稿件检验外推。从发表图裁出的子图仍可能保留作者为该版式预先裁好的宽高比，需用独立上传的原始素材另外测一次真实排版效果。

| 要验证的问题 | 比较方式 | 结果决定什么 |
| --- | --- | --- |
| 能提取可靠的训练样本吗 | 在人工框上核对子图识别、图注对应和公共图例归属，分别报告不同图型及人工修正耗时 | 定位错误多就先改提取和标注 |
| 模型真的理解写作目标吗 | 作者独立标注主图与配对，比较只看图、加图注、再加一句主张。加入同素材换主张的配对题，允许并列与弃权 | 判断哪些语义线索值得进入求解器 |
| 候选集合是否足够好 | 在测试论文上同时报告“候选中最好的一份”和“模型首选”的复原度、邻接关系保留率及覆盖失败数 | 最好候选也差就改结构生成。差距出在首选就改排序 |
| 用户是否更愿意采用推荐 | 原 v0.2、纯结构检索、加内容的排序三组消融。作者或读者在目标版心下盲选，记录首轮采用、平局、都不可用及后续修改时间，按稿件汇总 | 人工评价决定是否启用新默认排序 |
| 能否继续交付稿件 | 同一候选重放、撤销和 SVG 导出。本机 Illustrator 检查文字、裁剪和独立对象 | 几何正确与编辑能力作为交付条件 |

现有八幅图的小实验里，45 个合法候选上，v0.2 首选的平均外框 IoU 为 0.346，单靠几何学习的首选为 0.145，候选中的最好值为 0.554。这些数字衡量对已发表位置的复原度。原始比较可用 `git show ecc866e:experiments/journal-layout/README.md` 复查。另一轮参考框实测在已知面板数量时匹配 25/41 个面板。这两组结果说明，应分别测量识别、候选覆盖和最终选择。[参考框验收](../examples/reference-preferences/acceptance.json)

建议第一个实验按图型与期刊分层，从 30–50 篇独立论文中整理约 100 幅经核对的组图。该数量是控制标注成本的起点。先预留整篇论文和整簇转载图，再用逐步增加的训练论文绘制学习曲线。另选作者愿意给出目标的新稿做盲评，原稿、候选与反馈保留相同素材 ID，分别统计图框提取质量、布局复原质量和实际采用情况。

首轮经费适合投入人工校正与盲评。PDF 解析、条件统计、有限搜索和小型排序器可在 CPU 上运行。预训练视觉模型可复用已有支持图像输入的服务，也可本地推理。若开发验证显示分图误差占主导，可用 GPU 微调检测器。若高质量候选的覆盖不足、学习曲线随独立论文持续增长，再比较带约束的树生成模型或 Transformer。[受约束布局生成研究](https://arxiv.org/abs/2208.08037)

强化学习可留给有多轮交互记录的场景，例如系统提出修改后作者逐步接受、调整或撤销。v0.3 当前首轮决策可以直接用成对盲选评价。只有当多轮数据能定义可靠奖励，并能在同一批稿件上超过简单排序，才值得为强化学习调配显卡。
