# v0.2 engineering decisions

## Saved state

The figure remains a schema-1 document. A saved revision, an AI candidate reconstructed from its root, and a pointer gesture each have separate state. The project menu retains the existing soft-delete, restore and undo history. Project packages contain editable figure content and assets.

SQLite tracks its schema in `user_version`. Before upgrading an existing recognized database, the server takes a consistent SQLite snapshot with `VACUUM INTO` under the data directory’s `backups`. Migration DDL and the version update use a transaction. Older embedded job results get their two nullable candidate provenance fields at read time. Assets are addressed by project and asset UUID. A schema-1 package can be opened in multiple projects with the identical document hash; asset removal or replacement in one project stays local to it.

## Continuous refinement

Every submitted turn freezes the project, root hash, source hash, selection, edit scope and engine versions. The server resolves the parent, replays the cumulative commands and validates their result. A clarification retains the working candidate, earlier questions and previous answers. The chain limit counts clarification turns and the command limit applies to the entire draft. Acceptance is a single normal revision. The editor can compare a stale draft with its root, or explicitly request a new draft.

The selection check compares the result with this turn’s working document. It expands a selected group member into the whole group. This allows a selection-scoped child of a previous whole-document edit while protecting other panels and global fields. The model receives structured information, and the interface computes change lists from document fields.

## Rendering and measurement

Preview and export requests persist a job before doing the work. The Fastify process snapshots immutable asset references. Two reusable Node worker threads perform SVG compilation and PNG rendering without receiving a database handle. PNG cache entries include the document and normalized asset hashes, pixel dimensions, SVG renderer version and font registry version. The memory cache holds at most 32 MiB of PNGs. Publishing an artifact, the terminal job and its event uses one short transaction after checking cancellation, deletion and versions.

Fontkit shapes editor-generated labels with one of four bundled font files. Metrics distinguish advance from ink and include the face fingerprint. Old documents keep their stored geometry. A change to a label must preserve or improve each pre-existing canvas overflow. Strict layouts validate all visible labels. Chromium tests compare SVG advance and rasterized ink separately because the SVG bounding box can include the font’s line box.

## Local rows and input

Local rows align the content tops and account for ink on all four sides. A rigid group can translate in preserve mode. Equal width and equal height use the cropped aspect ratio and search a single scalar against region capacity. Locked objects, crossing constraints and obstacles produce typed failures. Dragging a label writes its relative baseline offset. List sorting changes the numbering order. The workspace records a single transaction for a completed gesture.

## Reproducing desktop checks

The Chromium tests start the API and web server with Node on Windows and Linux. `PANELSTUDIO_E2E_API_PORT` and `PANELSTUDIO_E2E_WEB_PORT` select a separate pair when another instance is running. The server integration tests poll jobs through the public API.

The Illustrator input generator creates its own temporary database, uses the real import, transaction and export routes, and generates five mixed sets. The desktop check measures native objects, changes text and a Bézier handle, moves each panel, saves separate native files and reopens them. Actual build numbers and observations are in the [Illustrator record](illustrator-compatibility.md).

Direct SVG import in Illustrator 30.7 selected the Medium CJK face on this host despite the declared 700 weight. The SVG preserves the portable family name and native text. The existing font bundle now also provides an Illustrator script that identifies editor-generated labels by panel UUID and selects the exact installed PostScript face. The native reopen check verified all three affected labels.
