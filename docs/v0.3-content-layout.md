# 按内容与投稿目标排版

这项功能使用用户在设置里填写的支持图片输入的兼容 API。调用时提供作者的排版目标、整图预览、逐个子图的独立预览和相关的参考版式。模型直接输出排版指令，编辑器显示可预览、应用和撤销的图稿。

## 使用路径

1. 首次导入素材或新建项目时填写目标期刊、研究领域、这幅图要说明的内容和排版偏好。所有文字项都可留空。
2. 在设置中填写模型地址、模型名称和密钥，启用图片输入。图像经现有图像传输选项或“按内容排版”按钮发送到该模型。
3. 保存排版目标后，主工具栏在视觉 API 可用时显示“按内容排版”。AI 面板也提供同名入口，可作用于当前选区。
4. 查看草案，可继续用自己的话修改，再一次应用。项目菜单和 AI 面板中的“排版目标”可修改期刊与偏好。

用户最新的明确要求优先，接着是该稿件保存的偏好、相关的已采用版式和论文版式。当前偏好提供“结合内容安排”“同组图便于比较”“突出主要结果”“紧凑清晰”。对比、主次和阅读顺序在模型内部判断，直接进入已有排版器和约束检查。

## 参考材料与采用记录

服务从数据目录下的 layout-references.json 读取已核对的版式，按排版单元数量、期刊名称、研究领域与论文标题挑选至多六个例子。每个例子有标识、来源类别、期刊、领域、可选论文标题与链接、子图类型、整体宽高比和归一化区域。它们是结构记录，模型按照当前的素材映射到对应位置。模型输出的参考标识和映射由服务核验。

本机演示库接入了 TAC 第一轮整理的 112 个论文组图和评阅者选择的 8 个版式，全部通过当前切分结构检查。这份本地材料的领域以靶向蛋白降解为主。领域与期刊缺少匹配时，模型仍可根据用户图稿提出方案。系统提示仅允许把提供的具体来源作为已检索文献，期刊名称本身不触发模型凭记忆修改投稿尺寸。

用户应用过的布局会与项目修订一起记录。记录包含几何位置和项目领域，支持刚性编组。撤销后失效的采用记录退出后续参考，重做后重新恢复。软删除的项目退出查询。用户的采用只作为正向示例，其他未采用候选的偏好状态保持未知。

研究实验中的库可以通过以下入口导出，实际工作目录和服务数据目录由使用者指定。

~~~powershell
python experiments/layout-learning/export_library.py 工作目录 服务数据目录/layout-references.json --field "研究领域" --metadata Zotero导出的.rdf
~~~

## 实现与兼容

文档新增可选 publicationContext。旧 schema 1 文档可以继续打开，设置修改使用普通事务，因此可保存、撤销、重做并随工程包导出。SQLite 版本从 3 升为 4，迁移前先备份现有数据库，旧素材表仅在早于版本 3 时迁移。

每次模型任务冻结选中的参考材料，排队期间参考库变化不会改变该轮任务的输入。整图和独立子图受图片输入开关控制。选区任务只提供选区的独立子图，并通过既有编译器检查编辑范围。模型没有有效参考标识、重复映射、跨出选区或违反锁定与布局约束时，候选不能被应用。

## 本机验证

2026-11-12 已完成接口与文档测试、浏览器操作测试。模型接口验收使用本地可控响应服务，核对图像输入、作者目标、参考筛选、草案应用、撤销重做和 SVG 导出。外部厂商模型的实际视觉判断仍需要在用户配置 API 后验证。演示数据中的模型设置和密钥当前为空。

界面继续采用既有四档字号。浏览器测试覆盖中文桌面、英文窄屏和新增目标表单。真实请求经配置的兼容 API 发出，视觉部分没有引入新的本地训练模型。
