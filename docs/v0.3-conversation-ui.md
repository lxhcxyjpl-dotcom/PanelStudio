# v0.3 开发中：上手引导与对话交互

本次调整以 ChatGPT 的对话使用方式为参考，保留 PanelStudio 的科研画布、品牌和暖色底。公开官网在本次查看时停留于访问验证页，因此这里不声称与其最新页面逐像素一致。

## 用户路径

- 首页以一句话目标输入为中心。用户可以直接输入、选择一个起始想法，或导入图片。导入后，首页文字会带入排版目标窗口；在保存前仍可修改。
- 首次访问首页显示简短的上手入口，不强制弹窗。三步引导介绍导入、排版、采用与导出，可以跳过或回退。完成后可直接打开示例。在已有项目中重开引导时，末页返回原图稿，不向现有图稿加入示例。
- 右上角书本按钮和项目菜单均可重新打开「快速上手」。浏览器仅记住是否收起过入口，键为 `panelstudio.onboarding.v1`；不写入服务端或用户长期记忆。
- 排版目标先填写图稿重点，再补充期刊与领域。四种偏好改成原生单选卡片，支持鼠标和键盘。目标仍走原有文档事务，随项目保存、撤销和工程包保留。
- AI 区上方保留目标入口，中央为历史对话与草案，底部固定输入框。问题与回复分开呈现，草案提供原稿对比、修改摘要、采用、继续调整、手动编辑和丢弃。修改明细按需展开。
- AI 未配置时显示连接入口，仍可填写示例指令。图片发送开关与提示、选区范围、失败原因、过期草案提示保留可见。视觉复核与常用指令收在附加选项里。

## 输入与状态

Enter 发送，Shift+Enter 换行，Ctrl/Cmd+Enter 也可发送。输入法组合期间的 Enter 不发送。后端接受请求后，只清空与本次发送完全一致的输入；用户提前输入的新内容保留。失败、暂不支持或取消时，若输入框仍为空则恢复请求文字，便于修改或重试。

停止按钮独立于发送按钮，并阻止默认表单动作，避免取消后立即重新提交。历史消息独立滚动；阅读旧消息时不会强制跳到最新，用户可以点击「回到最新」。输入框在桌面侧栏和手机抽屉中都保留位置。

页面继续只使用 **13、15、24、56 px** 四档字号（通过可随根字号缩放的共享变量），科学图稿本身的编号字号独立。窄屏首页使用已有的 24 px 档位。所有新增交互支持中英文和深浅主题。

## 实现位置

- `apps/web/src/ui/StartScreen.tsx`：首页目标输入、起始想法、首次提示与最近项目。
- `apps/web/src/ui/Onboarding.tsx`、`onboarding-preference.ts`：三步引导及本地入口状态。
- `apps/web/src/ui/Dialogs.tsx`：排版目标卡片与可滚动表单，标题和关闭按钮保留在表单外。
- `apps/web/src/ui/AiPanel.tsx`：对话、固定输入框、状态与草案操作。
- `apps/web/src/state/candidate-session.ts`：提交后输入清理和失败/取消后的恢复。
- `apps/web/src/studio.css`、`i18n/catalog.ts`：视觉和双语文案。

## 验证范围

前端类型检查、13 项前端单元测试与生产构建通过。浏览器使用本机 Edge、隔离测试数据库与本地模拟模型服务。15 个不同浏览器场景已通过，包括三步引导到示例导出、首页目标带入及保存、320 px 深色英文界面、四档字号、API 图片输入、连续草案精修、取消、失败、过期、输入法与换行。相关文件为 `onboarding.spec.ts`、`ai.spec.ts`、`publication.spec.ts`、`typography.spec.ts`。

截图记录位于 `.panelstudio/acceptance-interaction-20261113/`；对话截图中的图块与模型回复是测试夹具，用来检查交互。它们不是新训练模型或真实外接视觉模型的效果证明。本次没有重新执行 Illustrator 验收；浏览器流程实际生成了可编辑 SVG 下载。
